# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

# КУСЬ.io

A browser game in the spirit of agar.io: soft candies bite pieces off each other, and the wounded one keeps eating. Canvas 2D, no libraries, no server. Played on PC and on phones (the iPhone must work).

- Site: https://antropos17.github.io/kus-io/ (GitHub Pages, branch `main`, repository root)
- The game's interface is in Russian, code comments are in English

## Commands

```
npm install        once: prettier and playwright-core
npm run build      build index.html from src/
npm test           build and run the tests in headless Chrome (needs an installed Chrome)
npm run format     prettier over src/js, tools, tests
node tests/run.mjs soak    only the tests whose name contains "soak" (no build: run npm run build first)
node tools/wrap-curve.mjs 30 normal    the autopilot's runaway-wrapper catch rate and its share of a run's sugar (see docs/stages.md «Фантик»)
npm run check      exit with an error if index.html does not match src/
npm run og         rebuild og.png, the 1200×630 link preview picture, from a real frame of the game
npm run shots      rebuild the README screenshots in docs/media/ from real frames of the game
npm run sfx        rebuild src/js/05-sound-data.js from tools/sfx.json, then build (needs ffmpeg and the earshot takes on disk)
```

The tests use the installed Chrome (`channel: chrome`); another binary: `CHROME=/path/to/chrome`. Every test browser is pinned to `locale: 'ru-RU'` (headless Chrome is English, and the game picks its language from the browser); `open({ locale: 'en-US' })` gives an English page.

Deploying: `npm test`, commit `src/` together with the built `index.html`, `git push`. Pages updates within a minute.

## The main rule

`index.html` in the root is GENERATED. Edit only `src/`, then `npm run build`. The built file is committed: Pages serves it, and it is also a self-contained page (one file, no requests except fonts) that can be sent around or opened as `file://`.

`og.png` in the root is the preview picture for chats (`og:image`). It is a separate file next to the page: the page does not load it, so it does not break the "one file" rule. The tab icon is embedded in `<head>` as a data-URI SVG.

Sound takes are made outside the repository with earshot (https://github.com/Leonxlnx/earshot, MIT) and embedded as data, so the page stays one file. `tools/sfx.json` says which earshot design plays each event and names the folder with the takes (`src`); `node tools/sfx.mjs pick <event> <design|synth>` swaps one and rebuilds. An event set to `null` there plays the synth. The takes were picked from earshot's descriptions and measurements: nobody has listened to them in the game yet.

## How it is put together

`tools/build.mjs` inserts `src/style.css` and all of `src/js/*.js`, in name order, into the template `src/index.html` at the markers `/*__CSS__*/` and `/*__JS__*/` (each exactly once). The JS pieces end up in ONE `{ ... }` block, so:

- all top-level `const`/`let`/functions are shared by all files, there are no imports;
- file order matters: a `const`/`let` from a later file must not be touched at the top level of an earlier one (TDZ). Inside functions it is fine;
- a new file gets a number by its place in the load order.

## Decisions that must not be broken

- No freeze frames and no pauses of game time on a bite: the player took them for hangs. Time slows down only when swallowing whole, in a smooth curve.
- No random camera shake: a kick goes through a spring (`cam.kx`, `cam.ky`, `cam.zk`). To give a kick: `cam.shake = strength; cam.sa = angle`.
- All movement is computed from `dt` and is the same at 30 and at 120 frames per second. Do not write "per frame" (`*= 0.9`), write it through `Math.exp(-dt * k)`.
- `calm` (the system setting "reduce motion") turns off flashes, camera kicks and the slow-down.
- Phone: the joystick appears under the finger anywhere on the screen, buttons «Кусь» (bite) and «Язык» (tongue), everything fits in 360×640 and in landscape 844×390. After interface changes look at both sizes.
- The difficulty `DIFFS`, the rescue from a lethal bite (`graceT`) and the allowances for a small player in `09-bots` keep a newcomer alive. Check the balance with the autopilot (`player.ai = newAI()`), not by eye.
- Stages are for free play only. In `t3`, `daily` and the world behind the menu the cake and the piranha packs come as before (`population` in `09-bots`); in a free run the piranhas come only as stage raids and the cake only as the boss. Thresholds are the player's peak mass of the life (150, 600, 1600) with time ceilings for the first two (0:45, 2:00); nothing new starts while the boss is on the field.
- The boss is the player's alone: bots neither bite it nor hunt it, and it bites only the player (`biteScan`, `botThink`). A win is a slow-down arc (`slowT`, `slowLen`, `slowDip`), never a freeze, and with cheats it does not count.
- The wrapper's reveal (the dimmed edges and the counting number after a catch) never pauses game time. The wrapper appears only in a clean run, after a ×5+ streak lapses on its own, at most one at a time. Bots ignore it; the player's autopilot chases it (that is how `wrap-curve` measures it).
- `sugarFly` is called after the sugar is added to `run.sugar`, in the same turn: the cubes only show a sum that is already paid, and the pill's odometer catches up when they land.
- The trophy card is only for beating the Big Cake (`run.won`). Death, `t3` and `daily` keep the ordinary end card.
- The page stays one file with no external scripts. No syntax or CSS newer than what iOS 15 Safari has (`inset`, for example, has already been replaced).
- The ES5 script embedded at the start of `<body>` shows errors on screen. Do not touch it and do not move it to modern syntax.

## The album

A sticker opens when the player has swallowed that bot whole `NEED[tier]` times in runs without cheats (tier 0 once, the rarer tiers three times; the page shows the progress as «2 из 3»); a full row pays `ROW_SUGAR` sugar once. Each bot name has a fixed look in `BOT_NAMES` (flavour, pattern, hat), so the sticker matches the candy on the field. A row's tier in `ALBUM_ROWS` sets how often its names come onto the field (`TIER_W`) and how many swallows its stickers need (`NEED`). Pace the album with `NEED`, not `TIER_W`: fewer common names make the field a crowd of twins. Measure a change with `node tools/album-curve.mjs 30 normal` and `node tools/album-curve.mjs 30 normal 300 weak` (`album` gives the median stickers after 1, 3, 5, 10, 30 and 60 runs, `twinsOnField` the bots sharing a name), not by eye. With `NEED = [1, 3, 3, 3]` the autopilot opens 10–11 of 30 in 10 runs (weak: 10), 4 in the first run, and the field keeps about 8.7 twins, the same as before `NEED`.

- A new ordinary sticker: add the name to `BOT_NAMES` with its look and to one row in `ALBUM_ROWS`. Rows hold five stickers.
- A special enemy (hedgehog, piranha, cake): push an entry to `STICKERS` after the loop, for example `{ id: 'hedgehog', name: 'Ёж', row: 'special', tier: 0, take: (B) => B.kind === 'hedgehog', look: { pal: PAL_HEDGE, kind: 'hedgehog' } }`, and add a row `['special', '…', 0, ['Ёж', …]]` whose names are the entries' `name`. `paintSticker` dresses the stand-in in `look`, so `kind` brings its own drawing. Names of special rows are not given to ordinary bots: leave them out of `BOT_NAMES`. The `id` is the save key: never rename one.

## Performance

- `adapt` in `17-boot` lowers the detail (`lod` 0/1/2) and the resolution (`quality`) when frames drop or the script takes more than 62% of a frame. The canvas size changes mid-round no more than once every 12 seconds.
- Heavy in drawing: the mouth and face, the tray, body gradients. Body outlines and fills go through one `Path2D` per body (`buildPath`).
- In hot loops do not create needless objects and do not use `clip`, except in the places that already have it.
- The pause has «Показывать FPS» (show FPS): frames, the worst frame, script time, detail level.

## Tests

`tests/run.mjs` checks: startup on PC and phone, buttons within the screen, bite rules (hedgehog, cake, shield), the streak and the jelly (the streak's label, fuse, stamps and summary; the runaway wrapper, its reveal and payout; the cream-pill HUD on both phone sizes; the trophy card and its glaze), difficulty and graphics, every sound, a three-minute autopilot run on ragged frames (NaN, leaving the field, position jumps, stuck states). Add a check for a new mechanic there too.

The tests do not see the picture and do not hear the sound. Check the look with screenshots; nobody has checked the game automatically on a real iPhone.

## What is not there

- Multiplayer: it needs a server, for now all rivals are bots.
- Telegram Mini App: the code detects running inside Telegram, but no bot has been created.
