# Узоры как одна коллекция — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** все 19 узоров (кроме `plain`) перерисованы кодом в одном «материале», цена видна по богатству, четыре самых дорогих живые; кадр на телефоне не дорожает.

**Architecture:**
- Общие функции материала (`puff`, `gloss`, `glint`, `skinLayer`) рисуют плитку один раз в `skinTile`. Узоры на всё тело — на холсте 512 в координатах 256.
- `drawSkin` ставит плитку через `skinAt` с одной общей `DOMMatrix`. Живой слой (`a.fx`) рисуется только при `lod === 0`, `!calm` и достаточном размере на экране.
- `tools/perf.mjs` получает `SKIN=<id>` для худшего случая. `tools/skin-shots.mjs` снимает одинаковые кадры «до» и «после».

**Tech Stack:** ванильный JS в одном блоке (`tools/build.mjs`), Canvas 2D (`Path2D`, `shadowBlur`, `CanvasPattern.setTransform`, `DOMMatrix`), тесты на `playwright-core` в `tests/run.mjs`.

**Spec:** `docs/superpowers/specs/2026-11-27-skin-art-design.md` и `CLAUDE.md` (разделы «Decisions that must not be broken», «Performance»).

**Где работать:**
- Отдельный worktree, ветка `skin-art` от `main` (c2769de).
- `CLAUDE.md` в этой ветке не трогать. В основной папке там лежит незакоммиченная заметка владельца, и правка в ветке помешала бы ей при `git pull`. Новые возможности описать в шапке `tools/perf.mjs` и в самом `tools/skin-shots.mjs`.
- Скретч-файлы другой сессии в `.claude/` не добавлять в коммиты.

## Global Constraints

- `index.html` генерируется: править только `src/`, потом `npm run build`, в коммит класть `src/` вместе с `index.html`.
- Одна страница без картинок и внешних запросов. Ничего новее iOS 15 Safari: в `src/js/02-tuning.js` нет `.filter =`, `roundRect`, `createConicGradient`.
- Ид узоров, их порядок в `SKINS` и цены в `WARDROBE` не меняются.
- Светотень плитки круглая, без направления: плитка поворачивается с `b.fa`.
- Живой слой: только `lod === 0`, `!calm`, `b.Rs * cam.z >= FX_MIN` (`FX_MIN = 16`). Движение — от часов `last / 1000`, никаких «на кадр».
- В `drawSkin` и `skinAt` никаких `new` и литералов массивов/объектов на вызов.
- Нового видимого текста нет.
- Перед коммитом: `npm run format`. Тексты коммитов и PR показать владельцу до `git push`.
- Приёмка скорости — из спеки, раздел «Замер скорости».

## Review Focus

- **«Уменьшить движение» (`calm`):** живых слоёв нет, радуга стоит. Тест в Task 2.
- **Мелкая конфета и `lod` 1–2:** живого слоя нет, лишних заливок нет. Тест в Task 2.
- **Старт игры:** `renderSkins` при загрузке рисует все 20 плиток (8 из них на 512, с `shadowBlur`), и первый кадр может опоздать. Порог в Task 5. Если не проходит, плитки для меню рисовать при первом открытии раздела «Конфета».
- **Толпа одинаковых живых узоров:** боты тоже носят `galaxy` и `rainbow`. Худший случай `SKIN=galaxy` замеряется в Task 5.
- **iOS 15:** запрещённые вызовы ловит тест в Task 2 (чтение `src/js/02-tuning.js`).

- [ ] **Step 3: `skinAt` и `drawSkin`.**
  `skinAt` пишет поля общей `skinM`, которая создаётся один раз:

  ```js
  k = (span * b.Rs) / W; cs = cos(ang) * k; sn = sin(ang) * k;
  m.a = cs; m.b = sn; m.c = -sn; m.d = cs;
  m.e = b.x - (cs - sn) * W / 2 + cs * dx; m.f = b.y - (sn + cs) * W / 2 + sn * dx;
  pat.setTransform(m); ctx.fillStyle = pat; ctx.fill(b.path);
  ```

  `drawSkin`:
  - основа: `skinAt(a.pat, a.c.width, a.span, b, b.fa, flowDx)`. У `flow` при выполненном условии живого слоя `flowDx = ((T / period) % 1) * W`, иначе 0;
  - живой слой, если условие из Global Constraints выполнено и `kind !== 'flow'`. Здесь `T = last / 1000 + b.ph`;
    - `sweep`: `dx = ((T / period) % 1 - 0.5) * W`;
    - `drift`: `dx = sin(T * 0.35) * W * 0.08`, `globalAlpha = 0.55 + 0.45 * sin(T * 0.9)`;
    - `spin`: угол `b.fa + T * speed`, `globalAlpha = 0.6 + 0.4 * sin(T * pulse)`;
  - `globalAlpha` вернуть в 1;
  - ошибка в `try` обнуляет `a.pat`, как сейчас.

  В конструкторе `Blob`: `this.ph = rand(0, 60)`.
