# Английская версия — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** весь видимый текст игры есть на русском и английском, язык выбирается по языку телефона, выбор игрока в настройках сохраняется в `kus.lang` и применяется перезагрузкой.

**Architecture:** новый файл `src/js/01-lang.js` (грузится раньше `02-tuning`) держит `LANG`, таблицу строк `STR` (ключ → `[ru, en]`, строка или функция для шаблонов и чисел), таблицу английских имён `EN_NAMES` (русское имя-ключ → английское) и функции `t`, `nameOf`, `accOf`, `applyLang`. Статический текст `src/index.html` размечен `data-t`/`data-th`/`data-ta` и подставляется `applyLang` при загрузке. Русские имена конфет остаются ключами (`Blob.name`, `kus.album`, инструменты), на экран идут через `nameOf`/`accOf`.

**Tech Stack:** ванильный JS в одном блоке (`tools/build.mjs`), Canvas 2D, тесты на `playwright-core` в `tests/run.mjs`.

**Spec:** `docs/superpowers/specs/2026-11-26-english-design.md`

## Global Constraints

- `index.html` генерируется: правим только `src/`, после правок `npm run build`.
- Одна страница, без внешних скриптов; синтаксис и CSS не новее iOS 15 Safari.
- ES5-скрипт показа ошибок в начале `<body>` не трогать и не переводить.
- Верхнеуровневые `const`/`let` более позднего файла нельзя трогать на верхнем уровне более раннего (TDZ).
- Русские имена (`BOT_NAMES`, `FLAVORS`, особые враги, `BOSS.name`, имена наклеек, id рядов) — ключи; их значения не меняются.
- `LANG`: `kus.lang` (`'ru'|'en'`) важнее языка телефона; язык телефона `ru`, `be`, `kk` → `'ru'`, иначе `'en'`; чтение хранилища в `try`.
- Переключатель языка только в настройках меню, в паузе скрыт; смена = запись `kus.lang` + `location.reload()`. Название языка на кнопке на своём языке: «Русский», «English».
- Бренд-слова EN (дословно): логотип/заголовок `KUS.io`; кнопка «Кусь» → `Kusь!`; «Язык» → `Tongue`; «Кусь-кусь!» → `Kusь-kusь!`; «Ням!» → `Yum!`; «Хрум-хрум!» → `Crunch!`; «Обжора!» → `Nom-nom!`; «На волоске!» → `Close call!`; «ещё кусь!» → `one more Kusь!`; «Ещё кусь» → `One more Kusь`; «кусь лидера!» → `Kusь the leader!`; «Последний кусь: X» → `Last Kusь: X`; «Фантик» → `Wrapper`; «Лови!» → `Catch it!`; «Конфета дня» → `Candy of the Day`; «Большой Торт» → `Big Cake`; сахар → `sugar`; имя по умолчанию «Кусака» → `Kusaka`.
- Имена конфет по-английски — английские сладости, без транслита, все различны.
- Тон перевода: игривый и короткий, как в русском. Не влезает — сокращаем текст, а не шрифт.
- Метатеги `og:`/`twitter:`, `og.png`, README и `tools/og.mjs`/`tools/shots.mjs` остаются русскими.
- Всё видимое проверяется на 360×640 и 844×390 на обоих языках. Русская версия не меняется ни на вид, ни по смыслу.
- Коммиты локальные, без `git push` (пушит только пользователь или по его просьбе).

  const vis = (e) => e.offsetParent !== null || getComputedStyle(e).position === 'fixed';
  for (const e of document.querySelectorAll('body *')) {
